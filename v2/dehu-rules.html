DEHU RULES

「的呼」推算規則說明

回到逐日的呼查詢

「的呼」屬於喪葬擇日中的一項避忌，用來查某一日會「呼」到哪些亡命生人。此頁把查詢頁採用的規則集中整理，方便與主系統同站引用。

KEY

一、核心邏輯

日柱 → 納音 → 五音 → 排圖 → 日支位置 → 的呼
  1. 先定日柱，例如甲子日、丁卯日、戊辰日。
  2. 查日柱納音，例如甲子為海中金，丁卯為爐中火。
  3. 由日柱納音五行反推所屬五音。
  4. 選用對應的宮、商、角、徵、羽五音排圖。
  5. 依日支找出其在子、丑、寅、卯……亥中的位置。
  6. 依紅字順排、藍字逆排，查出相呼之亡命生人。

TONE

二、五音與納音對應

先看日柱納音，再歸五音
五音 固定干序 日柱納音五行 說明 速記

READING

三、排圖判讀

紅字順排

順

依十二地支順序前行：子 → 丑 → 寅 → 卯 → 辰 → 巳 → 午 → 未 → 申 → 酉 → 戌 → 亥。

藍字逆排

逆

由同一組干序反向推回，用來判定排圖中另一側的相呼關係。

箭頭後五音

標

查詢頁保留「某某人 → 宮／商／角／徵／羽」的表內標記。此為表內分類標記，不可直接誤認為亡命本人納音。

實務提醒

合

「的呼」只是喪葬擇日參考之一，仍須合看地支沖、納音剋、山向、歲月日時、入殮移柩安葬法等條件。

EXAMPLES

四、查詢頁採用示範

甲子日 海中金 → 宮音

子位查得：辛丑人 → 徵音（火）。

結論：甲子日的呼辛丑生人。
丁卯日 爐中火 → 角音

卯位查得：甲戌人 → 商音（金）；甲午人 → 宮音（土）。

結論：丁卯日的呼甲戌、甲午生人。
戊辰日 大林木 → 羽音

辰位查得：癸酉人 → 宮音（土）；癸未人 → 羽音（水）。

結論：戊辰日的呼癸酉、癸未生人。
