# v2.8 穩定會員驗證修正版

本版撤回 v2.6/v2.7 的自製 session/localStorage/逾時守門機制，會員登入與 session 讀取恢復為已在實站驗證成功的 v2.0 Supabase Auth 流程。

只在 profile 成功讀取後加入三級方案權限：
- 一般會員：只能進四大吉時；四大吉時只開臺灣當月＋下一月。
- 正式會員：全部查詢可用；流年法說明、個人流年法說明、人命擇日說明不可用。
- 永久會員：全部可用。
- 管理員：全部可用＋會員管理。

四大吉時頁改為等待 `tianshu:member-ready` 後再初始化，不再輪詢、不再自行做第二套驗證。
