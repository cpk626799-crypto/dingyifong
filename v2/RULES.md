# 本版採用規則摘要

完整說明請開啟網站中的 `rules.html`。

## 新增凶煞

- 病符：取太歲後一辰，以太歲年干五虎遁成完整干支。
- 劫煞：申子辰見巳；亥卯未見申；寅午戌見亥；巳酉丑見寅。
- 災煞：申子辰見午；亥卯未見酉；寅午戌見子；巳酉丑見卯。
- 墓煞：宅墓煞系統，命後五辰為墓。

四項凶煞皆放入九宮盤，以顏色標註。


## 流年紫白・月紫白採用規則

1. 流年年星依年數逆行，一年一星。公式：`MOD(10 - MOD(西元年, 9), 9) + 1`。
2. 年星或月星入中後，依「中宮5 → 乾宮6 → 兌宮7 → 艮宮8 → 離宮9 → 坎宮1 → 坤宮2 → 震宮3 → 巽宮4」順飛九宮。
3. 月紫白以年支分三組起正月星：子午卯酉年正月八白入中；辰戌丑未年正月五黃入中；寅申巳亥年正月二黑入中。之後逐月逆退一星。
4. 月序採節氣月：正月寅月自立春起，二月卯月自驚蟄起，三月辰月自清明起，依此類推；不是農曆初一換月。
5. 九星定位：一白桃花、二黑病符、三碧是非、四綠文昌、五黃大凶、六白偏財、七赤破財、八白正財、九紫喜慶。


## 逐日入殮移柩安葬的呼
本版新增 `dehu.html` 查詢頁與 `dehu-rules.html` 說明頁。採用規則：日柱 → 納音 → 五音 → 排圖 → 日支位置 → 的呼。五音對應為：金歸宮、水歸商、火歸角、土歸徵、木歸羽。
