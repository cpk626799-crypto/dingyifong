# v0.6 深色儀表板 UI 原型說明

網站名稱：天書三式•丁一峰老師術數查詢系統

## 視覺方向

- 深藍黑底：營造術數系統、夜空、星盤感。
- 金色主標：對應「天書」「三式」「術數」的典雅感。
- 卡片式模組：將輸入、結果、九宮盤、規則說明分層。
- 左側控制欄：集中日期、入中干支、年命、坐山等查詢條件。
- 右側結果區：集中四柱摘要、吉神凶煞、九宮盤、完整飛宮表。
- 響應式設計：桌機為左右分欄，手機自動改為單欄。

## 色彩

- 背景：#080b15 / #0d1220
- 卡片：rgba(20, 27, 49, .88)
- 金色：#d9b85b / #f3d579
- 文字：#e8edf7 / #f7edd1
- 輔助文字：#9aa6bb

## 功能頁

1. `index.html`：祿馬貴吊替飛宮
2. `zibai.html`：流年紫白查詢
3. `rules.html`：本版採用規則
